# 小红书对标笔记拆解

你收藏了几篇同行的笔记，想弄明白别人怎么起标题、第一段怎么留住人、结尾怎么引导读者行动。把公开笔记的链接交给这个工具，它会给你一份浏览器能打开的拆解报告，再把可以借用的写法整理成一份 AI 写作指南。

## 第一次用，先挑两篇笔记

1. **装好工具。** 在电脑上用 Codex 或 Claude Code，按[安装指南](https://github.com/DalinChen255/dl-skill/blob/main/docs/安装指南.md)安装 `dl-xhs-benchmark`，再开一个新对话。电脑需要 Python 3.9 或更新版本。
2. **准备取数用的密钥。** 工具通过 TikHub 读取小红书的公开笔记，调用接口可能产生费用。登录控制台，查看小红书接口的权限和计费，再创建自己的 API Token。[TikHub 控制台](https://user.tikhub.io/)
3. **先检查配置。** 在新对话里发「请找到小红书对标工具，给我一条在我电脑终端运行环境检查的命令，先不采集。」把它给的命令放进自己的终端运行，在终端提示时粘贴密钥。看到“环境准备完成”就可以继续。密钥保存在本机，也支持通过环境变量 `TIKHUB_API_TOKEN` 读取。
4. **贴上链接。** 在小红书打开笔记，点「分享 → 复制链接」。第一次选两篇写同类事情的笔记，把下面两行占位文字换成自己的链接，发到刚才的 AI 对话里。

```text
帮我拆解这两篇小红书笔记，每篇怎么开头，中间怎么讲，结尾请读者做什么？做完把报告和写作指南都给我。
第一篇笔记的链接
第二篇笔记的链接
```

也可以拆一个博主。复制他的主页链接，告诉 AI「帮我拆这个博主点赞最高的 3 篇」。工具会先翻页读取主页的笔记清单，排好点赞顺序，再读取选中笔记的详情。如果手里已经有想看的几篇，直接贴笔记链接，能省去扫描整个主页这一步。

## 怎么看结果

让 AI 给你两个文件的保存位置。先打开文件名以 `_拆解报告.html` 结尾的网页，挑一篇你熟悉的笔记，看它用哪句话开头，接着给了什么例子，又怎样收尾。视频笔记按接口返回的标题和正文拆解，视频里的口播需要另外提供文字。

再打开 `_写作指南.skill` 结尾的文件夹，里面有一份 `SKILL.md`。下次在能读本地文件的 AI 里指定这份指南，再说你要写什么。例如「我想写一篇第一次买手冲壶怎么选的笔记。借用指南里的开头和分段方式，保留我的口气。下面是我实际用过两把壶的体会……」。

如果只看见 `_数据底稿.md` 和 `_AI拆解任务.md`，说明脚本已经备好材料。回到同一个对话，说「读取刚才的 AI 拆解任务和同目录的数据底稿，生成 HTML 报告和写作指南，完成后给我路径」。这一步可以直接用已有文件。

## 遇到问题

| 你看到的情况 | 接下来怎么做 |
| --- | --- |
| 显示 401 或 403 | 401 时核对 Token 是否有效，403 时检查该 Token 的小红书接口权限。密钥只在自己的终端输入。 |
| 显示 402 或 429 | 402 时去 TikHub 查看账户余额，429 表示请求过于频繁，稍后再试。 |
| 提示无法解析链接 | 拆一篇用笔记的分享链接，拆账号用博主的主页链接。分享文案里如果还有一段文字，只复制其中的网址。 |

想查看脚本的具体用法，可以打开同目录的[运行说明](SKILL.md#跑起来的步骤)。

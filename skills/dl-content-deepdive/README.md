# 内容深挖访谈

你有件事想讲，打开文档却只写得出一个标题。带着这点想法来就够了。AI 会像采访一样，一次追问一个细节，最后用你的原话整理出口播稿、小红书笔记或公众号长文。通常预留 20 到 30 分钟；手里有观点、例子和草稿，可以直接拿来改。

## 第一次怎么开始

1. 按[安装指南](https://github.com/DalinChen255/dl-skill/blob/main/docs/安装指南.md)把 `dl-content-deepdive` 装进 Claude Code 或 Codex。手动安装可[直接下载 ZIP](https://github.com/DalinChen255/dl-skill/releases/latest/download/dl-content-deepdive.zip)。
2. 打开你平时写稿的项目文件夹，新开对话。把下面这句换成你最近真遇到的一件事，发给 AI。

   ```text
   用内容深挖访谈帮我写一条小红书笔记。上周我第一次摆摊，有人拿着菜单问了三遍价格。我想讲这件事，但还不知道从哪讲。
   ```

3. 它会确认你为什么想发、准备发在哪儿、写成什么样。已经讲过的直接沿用。访谈时你可以把语音转成文字，按平时说话的方式回答。

比如 AI 问「那个人第三次问价格时，指的是菜单上的什么？」你想起来「两杯组合价挨着单杯价，他没看出那行写的是两杯」。这一句就给稿子找到了可以讲给读者听的现场。记不清的细节，直接说记不清。

如果已经写了一半，也可以贴出草稿，说「这是我想发视频号的口播，事情和观点都在里面，保留我的原话，帮我把它讲顺」。

## 最后能拿到什么

| 你选的形式 | 你拿到的稿子 |
| --- | --- |
| 口播稿 | 可以直接读出声的正文。做短视频还会给封面文案、小红书标题和抖音标题。 |
| 小红书笔记 | 标题和正文。刚才讲到的经历会写进正文里。 |
| 公众号长文 | 带小标题的文章，跟着你讲的材料展开。 |

拿到稿子先读一遍。如果一句话你平时根本不会说，把那句换成你自己的说法，叫 AI 顺着它改。定稿时，它会问稿子、改稿记录、素材分别放在哪。三个都可以用同一个文件夹。怕记错位置，可以让它给出刚保存的文件路径，打开就能核对全文。

如果同意固定位置，下次在**同一个项目文件夹**开始就会沿用。要换目录，直接说「改保存位置」。同名文稿会覆盖；想留一份旧稿，先说明「这次另起一个文件名」。完整的访谈和整理规则见[工具说明](SKILL.md)。

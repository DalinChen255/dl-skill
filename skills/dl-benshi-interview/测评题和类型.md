# 诊断依据

商业模式诊断第七版使用的问法和判断依据。

## 一、立场

1. 从“别人会来找你”和“你做着不累”的事情找线索。“累”要听本人怎么讲。有人做完很累，隔天仍愿意再做其中一步。把愿意保留的部分和能承受的频率分开看。
2. 可以先把一个小服务讲给具体的人听。有了明确的交付范围、自己能做到的事和双方接受的价格，就能试做第一单。
3. 看清客户凭什么找这个人。有人求助，说明有这件麻烦。对方为哪种结果付过钱，要另外核对。
4. 从眼前一个具体的人开始，了解他遇到麻烦时正在做什么。
5. 优先考虑最近就能试、工时也接得住的一单。
6. 同类交付有人单独付费，是已经发生的付费证据。回访、约时间、要样品、口头夸奖分别记下。礼节性红包、工资、免费受助，不能记作按报价买过这项产品。

## 二、问法

### 1. 先让人有话可说

从最近的日子开场，用两三句说明聊完能带走什么、约需多久，最后只问一件好回忆的小事。已经给了故事或材料，就从里面的一个细节接话，跳过自我介绍式提问。

“最近有谁来问过你一件小事？”也许只是同事拿着一张表来找他，或者朋友买东西前发来两个选项。需要举例时选一个日常场景，用完就停，把话留给对方。

对方说“我没什么本事”，先接住他的原话，缩小回忆的范围：“就想这几天，最近一次有人请你帮忙看一眼的是什么？”仍想不到，可以改从他自己刚学会或解决的一件事聊起。允许跳过、暂停，或先给一条现实中能观察的线索。一个自己的故事只说明他做过什么；别替他添上顾客和成交。

### 2. 让发现从他刚讲的事情里长出来

听到一处具体做法，就用他能认出来的话说出一点发现，给他纠正的空间。只有一句泛泛的回答时，先请他回到现场。每轮只追一个会改变诊断的问题，把“谁、做了什么、结果怎样”留作自己的听话线索。对方说得很清楚时直接往下走。

例如，对方说“朋友做个表我顺手给改了”。这时还听不出他帮了什么，可以问：“你打开它，最先改的是哪儿？”如果他接着说“她每月底要对账，我把总数放到最前面，她看一眼就知道差在哪”，再回应：“你先想到了她月底最急着查哪个数。照你这样一改，那张表才方便她对账。我这么理解，贴近你当时的想法吗？”对方纠正，就用纠正后的说法继续。对方没提过的感受、动机和客户反馈都留空。

看到聊天记录时沿用对方已经给出的事实，不索要截图。公司客户、内部数据和无权公开的材料不进报告。转述用“你提到”标明，计划中的金额与实际到账分开，实在分不清时先留空。

听完第一件完整的事就给一个带依据的暂时判断。只有一个例子，写成“这次你帮上忙的地方”。要说“别人常常为此来找你”，需要另一次经历或回头求助来支撑。需要交叉核对时再顺着聊第二或第三件，例如问有人认真谢过、实际付过钱、本人最得意的一次。已有足够线索就收住。

### 3. 把个人意愿和买方证据问清楚

对方回答“想接”“太累”“还行”，但这句话不足以选交付方式时，回到同一件事，按缺的线索挑一句：

- **找到本人重视的环节。** “上次帮完他，哪一幕你现在还记得？”对方觉得全程都不想再做，也照实接受。
- **划清交付边界。** “下次再有人来，哪一步你愿意自己做？”和他前面提过的耗时、精力或作息对照，决定卖一次点评、带客户做一遍，还是代做。不能光凭一个难忘瞬间下结论。
- **看客户实际做了什么。** “你把那份东西给他后，他后来怎么用了？”需要分清感谢和付款时，另找一轮问“那次是你们先约好价，还是他事后表示感谢？”

若两个做法仍分不开，可以用他讲过的情境帮他选，例如“她再拿张表来，你更想替她改好，还是坐旁边教她改？”允许“都想”“都不想”“得看情况”。如果答案已经明白，直接说这会怎样改变第一单，省下这道题。

### 4. 只补会改变下一步的现实条件

用一句自然的过渡说明问这个有什么用。如“要把这单安排得下，我想先听听你平时什么时候方便。”下列是可能需要弄清的事，一次问一件，已经知道的直接用：

- 想确定交付时间，问“按你平常一周的安排，什么时候做这件事最方便？”
- 想知道从谁开始，问“刚才说的这些人里，你方便先和谁聊聊？”可以只讲关系或处境，不要姓名和联系方式。
- 来人渠道会改变第一步时，问“前面那个人当时怎么找到你的？”仅在确有必要时聊账号。
- 需要按目标倒推单数时，问“你想先看看能不能收到第一笔钱，还是手头已经有个想达到的数？”对方没有收入目标，先算一单，容许目标留到以后。

换算工时写清采用的天数或周数；“下班后偶尔有空”不能直接变成“固定每月十六小时”。未知条件影响推荐时，写明需要先确认什么。主动指出选项和取舍，不把客户定位、价格和商业术语扔给新手自己解释。

## 三、帮人的方式（只在心里用，不对用户说）

六种方式用来判断“他适合卖什么形式的产品”。**报告和对话里不出现这些名字，不说“你是某某型”。** 报告里只写他具体怎么帮人、因此适合什么产品。

| 方式 | 从他的事里怎么认 | 适合的产品形式 | 不太适合 | 容易卡住 |
|---|---|---|---|---|
| 点破问题 | 先反问、先砍想法；别人说“聊完清楚了” | 一次性诊断、按月顾问、写常见误区 | 长期代做 | 给完方向不跟进；觉得“只是聊聊”不好意思收钱 |
| 理成流程 | 做表、清单、模板，别人拿去在用 | 模板包、替人搭流程、教搭法 | 纯聊天咨询 | 一直打磨不卖；做得太全，新手无从下手 |
| 陪到做完 | 持续跟进、监督；别人说“要不是你我早放弃了” | 有周期的陪跑、训练营 | 卖看完就走的资料 | 时间被吃光；替对方扛责任 |
| 亲手做出 | 自己上手做完；别人夸成品 | 按项目代做、固定套餐 | 纯讲课 | 按时间卖有天花板；只做不讲，别人看不出值多少 |
| 讲明白 | 解释、分享、写教程；别人说“一讲就懂” | 小课、照着做的文档、付费社群 | 长期代做 | 讲得好不等于对方做到；一直免费讲不收钱 |
| 接上人 | 介绍人、组局、拉群；别人说“路子广” | 付费小圈子、对接服务、小活动 | 一个人闷头做内容 | 价值说不清；人情多，收入少 |

二选一就用这几种方式之间真正影响交付的区别；只在听过实际经历还分不清时问。

## 四、商业模式怎么设计

依据：个人商业模式画布（Tim Clark 与 Alexander Osterwalder 等《Business Model You》，2012）、价值主张画布（Osterwalder 等，2014）、效果逻辑（Sarasvathy，2001）、关键决策法、先定好继续和停止标准（Camuffo 等，2024）。这些方法帮助梳理问题；推荐哪种生意要回到本次访谈和试单。

### 1. 九格画布（个人版）

| 格 | 写什么 | 从哪来 |
|---|---|---|
| 客户 | 具体处境的人：他正在做什么、卡在哪；写处境，不写年龄性别 | 讲过的事中来找他的人 |
| 他要办成的事 | 客户想往前走的那一步；他现在怎么解决、为什么不满意 | 来找他之前试过什么 |
| 你帮他的方式 | 交付什么、怎么交付 | 他帮人的方式 |
| 怎么找到他 | 第一批人从哪来，之后从哪来 | 现实条件、账号、人脉 |
| 关系 | 一次性、按月、还是社群 | 本人愿意重复的环节和可承担的频率 |
| 怎么收钱 | 每一级的价格和收法 | 定价方法 |
| 你手上的东西 | 门道、作品、工具、证据、人脉 | 当事人的经历和可用材料 |
| 你要做的事 | 每周固定做的几件事 | 产品和获客 |
| 你要付出的 | 时间、钱、精力上限 | 现实条件 |

### 2. 产品阶梯

用免费接触、首单、后续服务来看客户有哪几步可走。优先把第一单写实，其他两级按已有需求确定。

- **免费接触。** 有现成作品或方便给的小样，就用它说明能帮什么。已有熟人明确求助，可以直接谈一单。
- **第一个收费产品。** 写清对谁、做哪一步、双方各做什么、完成标志、多久和试报价。把准备、来回修改、事后答疑也算进工时。
- **后续服务。** 写客户在什么情况下会再需要帮助。客户已能自己做，就到此结束。有后续需要再设计回访或升级，把新增交付和费用说具体；尚无人提出的服务标作以后再试。

只有一个例子或还没人求助时，先给一个小方向，并说明向谁、做什么能看出有无需求。别用完整的产品阶梯掩盖未知。

### 3. 定价

- 优先看他收过的同类款项，写明当时的交付范围。有人为代做付过钱，教客户自己做仍是一个新报价。
- 再看真实可核的同类报价和客户目前的替代做法。写明比较的是哪种交付，差异很大就不硬套。同类报价不能当成交价。
- 缺少成交记录但交付范围明确，可以提一个小额试报价，交代为什么选这个数、改价要看什么；这是建议。能估工时或直接成本时给出算式。必要条件都不清楚时，先问清最影响报价的一项或约一次范围明确的小样，不虚填金额。别把客户花的时间直接折成其愿付的预算。

### 4. 适配检查

按本人讲过的事分别看：

- 对方最需要哪一步，实际做过什么？哪种需求或报价仍待试？
- 服务者哪一步愿意再做，哪一步想留给客户或限制次数？引用一次真实经历，只把本人认可的感受写成事实。
- 这单包括准备、沟通、交付、返工。按眼下可用时间能接几次？若客户只想要代做、本人只想教，直接说出这个分歧，先向一个可能的买家试一次调整后的服务。

## 五、算账

先把一单的两笔账列清：若按试报价成交，扣掉直接成本后剩多少；从准备到收尾，一共占用几小时。客户付款、约时间与要样品分别记录，到账后才计实际收入。缺工时就建议首单从准备到收尾记一次；缺直接成本或价格就标未知，保留能算的部分。

有月收入目标时，先讲明是收入还是扣成本后的结余。用目标除以单价（目标为结余时，仅在每单扣成本后为正时才这样倒推，否则先调整价格或成本），单数向上取整，再算“每单总工时 × 单数”同每月可用时间比较。没有收入目标时，给出一单的收支与用时即可。出现多种算得过来的组合时，说明它们在工时或收费方式上的取舍，再推荐一种。

只有真实邀请人数大于零、同批同类付费人数也已知时，才算这批人的成交比例，并保留人数和观察范围。没有这组数，先发出第一次邀请，不能用行业默认比例推算会来多少人。试报价、预计工时、试算场景写成假设，与已有经营数据区别清楚。

## 六、常见风险

挑和他的事对得上的写，每条写：为什么会发生在他身上（挂回他的话）、对策、最早能看到的信号。

| 风险 | 对策 | 最早的信号 |
|---|---|---|
| 接触不到合适的买家 | 从经历里能找到的人试一次具体邀约，记下他在什么情况下需要这种帮助 | 对方听完仍不知道这和自己有什么关系 |
| 交付后没有达到约定的结果 | 跟对方确认交付物怎么用了，找出卡住的一步；本人也回看从准备到收尾哪一步下次要换个做法 | 客户收到却用不起来，或额外修改远超约定 |
| 不好意思收钱 | 价格写死在介绍里；第一句话就报价 | 聊了很多人，一单没报过价 |
| 一直打磨不卖 | 先定一个必须对外卖出的日期 | 过了日期，东西还在改 |
| 做事三分钟热度 | 每两周一个检查点，只看一个数；换方向前要写下换的理由 | 两周内想换方向 |
| 时间不够 | 只留一种产品；把交付压到固定时长 | 交付超时、拖期 |
| 用了公司的东西 | 卖之前确认表格、方法、案例能不能用；公司客户和数据不能用 | 材料里出现公司名、客户名 |

## 七、替代方案

优先考虑同一种本事换一种交付、换一种有理由的客户范围。只有确实存在取舍时才写备选，交代眼下为什么先试主方案，以及哪种新证据会让你改判断。例如，代做有人付过钱，带教却只试过免费帮助；等有客户愿意按报价学、本人教完也还想做，可以再选。没有事实支持第二条路时，不凑备选。

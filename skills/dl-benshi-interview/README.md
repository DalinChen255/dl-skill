# 商业模式诊断

想把自己会的事做成一门小生意，可以先聊最近有人找你帮的一个忙。约二十分钟，AI 会和你一起看清你帮了谁、做了什么、哪些环节你还想再做，再写一份《商业模式诊断报告》。没有卖过东西也能开始。

## 怎么开始

- 在普通 AI 聊天里，复制[提示词正文](提示词-通用版.md#提示词正文)，发到新对话。可以打字，也可以用语音回答。想中途停一下，就说“先停”，保留它给的续接卡。
- 用 Codex 或 Claude Code 时，将本目录整体放进相应工具的 skills 目录，在新对话里说“帮我找找我能卖什么”。[访谈规则](SKILL.md)、[诊断依据](测评题和类型.md)和[报告模板](报告模板.html)要放在一起。

## 报告里有什么

首页写清第一单可以找谁、做哪一步、怎样试报价，以及今天可以怎么开口。接着展开你愿意保留的工作、客户和产品、每单成本和时间、风险与其他做法。已经发生的事和要试过才知道的部分分开写。

试过一单，把客户的回应和自己做完的感受带回来。AI 会陪你看下次该改范围、价格、交付方式，还是另试一个方向。

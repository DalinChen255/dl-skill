# 商业模式诊断

不知道自己会的哪件事值得收费？拿一次别人找你帮忙的经历，就能开始。聊约 20 分钟，最后拿到一份针对你自己的《商业模式诊断报告》。已经接过单，也可以聊下一单该怎么改。

## 用平时的 AI 聊天，免安装

1. 打开[免安装提示词](提示词-通用版.md#提示词正文)。找到「提示词正文」，点文字框右上角的复制按钮。手机上看不到按钮，可以长按选中框内全文复制。
2. 打开你平时用的 AI，例如 DeepSeek，新建一个对话，把刚才复制的文字粘贴进去并发送。
3. AI 会先问最近有谁找你帮过一个忙。挑一件记得清楚的事，用自己的话回答。用打字或语音输入都行，不用交简历或准备客户名单。

下面是一段虚构对话，给你看看聊到多具体就够了。

> **AI**　最近谁找你搭过把手？
>
> **你**　朋友第一次摆摊，我帮她改过价目表。
>
> **AI**　你打开那张表，先改的是哪儿？
>
> **你**　原来只有菜名和单价。我把双人套餐单独列了一栏，她说这下能直接指给排队的人看了。

这几句能看出你在哪一步帮上了忙。下次有人带着菜单来，你更愿意替他改，还是教他自己改？你的回答会改变报告建议你卖的服务。以前只免费帮过忙也照实讲，到试单时才知道有没有人愿意出钱。

## 聊完怎么看报告

翻开第一页，你应该能读出**谁遇到了什么麻烦、你能替他做到哪一步、这周先怎么试**。完整报告还会列出支持判断的经历、九格商业模式画布、试报价和每单工时。一个价格如果还没向人报过，报告里应该写明是试价。

- **在普通 AI 里**，报告直接发在聊天里。收到第一部分后回复「继续」看下一部分；只想拿走最值得试的一步，可以说「给我一页简报」。
- **在能写文件的 Codex 或 Claude Code 里**，完整报告可保存为 `商业模式诊断报告-代号-日期.html`。打开 AI 给出的文件位置，双击该文件，用浏览器阅读。
- **下次接着聊**，中途说「先停」，把 AI 给的续接卡留下来。换普通 AI 新对话时，把提示词和续接卡一起发过去。试过一单后，也可以带回原报告和对方的实际回应，说「帮我复盘这次试单」。

## 在 Codex 或 Claude Code 里用

按[安装指南](https://github.com/DalinChen255/dl-skill/blob/main/docs/安装指南.md)选择你已经在用的工具，安装 `dl-benshi-interview`。手动安装也可[直接下载 ZIP](https://github.com/DalinChen255/dl-skill/releases/latest/download/dl-benshi-interview.zip)。解压后把整个同名文件夹放到指南指定的位置，保留里面的[访谈规则](SKILL.md)、[诊断依据](测评题和类型.md)和[网页报告模板](报告模板.html)。

安装后，新开一个对话，发这句话就能开始。

```text
用商业模式诊断，帮我找找我能卖什么。
```

# 商业模式诊断工具

帮助创意工作者和小企业主找到自己能卖、做着舒服、别人愿意付钱的那件事，设计自己生意的 1.0 版本。

## 它做什么

像一次商业诊断：
- 听你讲三件帮过人的真事
- 先说对你的判断（你反复被人需要的是什么）
- 问几道从你的事里现编的二选一
- 生成《商业模式诊断报告》：诊断结论、你手上有什么、商业模式设计、风险和对策、行动处方

约 20 分钟，报告包含：
- 四层结构：内核（你是谁）、商业（你卖什么）、营销（客户从哪来）、工具（AI 怎么帮你）
- 九格画布、三级产品阶梯、定价算式、月收入倒推、90 天行动计划
- 验证清单和真实反馈的更新机制

## 文件说明

- `SKILL.md` — Claude Code 和 Codex 的 skill 定义
- `测评题和类型.md` — 诊断依据：立场、问法、商业模式设计、算账、风险
- `报告模板.html` — 诊断报告网页模板
- `提示词-通用版.md` — 给豆包、ChatGPT、DeepSeek、Gemini 的通用提示词版本

## 使用

### Claude Code / Codex
直接在项目里使用 SKILL。

### 其他 AI 工具
复制 `提示词-通用版.md` 里的提示词正文，粘贴到 AI 对话，按提示进行。

## 状态

第六版，2026-11-27：报告改为《商业模式诊断报告》，按四层结构（内核、商业、营销、工具）和九格画布展开。从"本事类型"转向"商业模式设计"，重点是帮用户设计可走的第一版生意，而不是给用户贴标签。
